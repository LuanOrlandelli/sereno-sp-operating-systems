# Registro de apoio por IA — Operating Systems

Foi utilizado o ChatGPT como ferramenta de apoio na interpretação dos requisitos, planejamento da infraestrutura Ubuntu Server, revisão de comandos, configuração de rede NAT/SSH, PostgreSQL, ASP.NET Core, Nginx, serviços systemd, monitoramento e organização das evidências. As descrições são um resumo fiel das solicitações, não transcrições literais.

- Como provisionar rede NAT e acesso SSH a partir do Windows para uma VM Ubuntu Server no VirtualBox?
- Como instalar e configurar ASP.NET Core 10, PostgreSQL 16 e Nginx para publicar a API Sereno SP?
- Como aplicar migrações do Entity Framework Core e conferir a comunicação com o banco?
- Como criar um script Bash para monitorar CPU, memória e disco, registrando alertas em log?
- Como configurar um serviço systemd para reiniciar automaticamente após falhas e como comprovar esse comportamento?
- Como estruturar um repositório GitHub reproduzível com scripts e evidências para a disciplina de Operating Systems?

Os procedimentos foram executados e conferidos pelo grupo em ambiente virtualizado; a ferramenta não substitui os testes e a responsabilidade técnica da equipe.
